# M1 上手指南(当前可运行)

> 更新:2026-09-30 · 基线:nanobrowser v0.1.13(Apache-2.0)fork · 构建绿 ✅

## 它现在能做什么

- 侧边栏聊天 → 读取当前页面 → 通过 CDP 真实点击 / 填表 / 翻页(Planner + Navigator 双 agent)
- **Skills 技能系统**(设置页 → Skills 标签页):内置 5 个技能(页面摘要 / 表格提取 / 自动填表 / 翻页采集 / 谨慎模式),支持自定义技能、Always-on 常驻注入、JSON 导入导出;manual 技能的会话级选择在开发中
- OpenAI 兼容自定义端点开箱即用,无需改代码
- 已通过真实浏览器加载验证(扩展启用、界面渲染零错误)

## 安装(团队成员,2 分钟)

> **浏览器版本要求:Chrome / Edge ≥ 116**(Side Panel API 需 114;CDP 扁平会话需 116+)。注意:本机便携版 Edge 只有 109,跑不了侧边栏与真实操作,请安装正式版 Chrome 或新版 Edge。

1. Chrome / Edge 打开 `chrome://extensions`,开启右上角**开发者模式**
2. 点**加载已解压的扩展程序**,选择仓库根目录的 **`dist`** 文件夹
3. (可选)把图标固定到工具栏;点图标即打开侧边栏

## 配置模型(必做,DeepSeek 已验证 ✅)

1. 侧边栏欢迎页点"打开设置"(或扩展详情 → 扩展程序选项)
2. **Model Settings → 添加供应商 → DeepSeek**:粘贴 API Key;模型名默认已是我们账号可用的 `deepseek-v4-pro` / `deepseek-flash`
3. **Agent Models**:Planner 与 Navigator 各选一个(推荐:Planner = deepseek-v4-pro,Navigator = deepseek-flash;若任务卡住可先用 flash)
4. 保存,回侧边栏开聊

> 已修复:DeepSeek V4 系列默认开启思考模式会拒绝结构化输出的 tool_choice,我们在模型构造里禁用了 thinking(见 `helper.ts`),端到端已验证。

## 端到端验收(2026-09-30 ✅)

在受控测试环境完成全链路验证:配置注入 → 聊天发任务 → Planner 生成计划 → Navigator CDP 真实导航 → 读取页面 → 回答正确(标题/时间/地点全部命中),全程约 15 秒。

## 开发命令

| 命令 | 说明 |
|---|---|
| `pnpm install` | 装依赖(registry 已指 npmmirror;corepack 按 packageManager 自动用 pnpm 9.15.1) |
| `pnpm build` | 全量构建,产物在 `dist/`(加载用这个) |
| `pnpm dev` | watch 模式,改代码自动重建(扩展页需手动刷新) |
| `pnpm type-check` / `pnpm lint` | 类型检查 / ESLint |

## 边界与注意

- `chrome://` 页面与 Chrome 商店页:内容脚本与 debugger 无法注入,属正常限制
- CDP 执行时页面顶部出现**"正在调试此浏览器"黄条**:正常,任务结束自动解除
- API Key 仅存本地(chrome.storage.local);请勿将内部系统数据发给未授权的模型服务
