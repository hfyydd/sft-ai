# SFT AI 助手

团队内部使用的 AI 浏览器助手 Chrome 扩展:侧边栏对话 + 读取页面/PDF + 操控浏览器(点击、填表、翻页)。

基于开源项目 [nanobrowser](https://github.com/nanobrowser/nanobrowser)(Apache-2.0)二次开发。

## 核心能力

- 侧边栏对话:点扩展图标即开,全中文界面
- 读取页面:HTML 正文;pdf.js 支持在线 PDF 和用户明确授权的本地 PDF 文本层提取;扫描件走视觉模型降级,不宣称内置 OCR
- 操控浏览器:CDP 点击/输入/翻页/切标签页;任务运行状态、事件、检查点和来源证据持久化,侧边栏断开不会自动取消任务
- 模型接入:OpenAI 兼容端点(DeepSeek / 本地 WPS-Comate 代理 / 任意兼容服务)
- Skill 系统:内置页面摘要、表格提取、自动填表、跨页任务等技能,支持自定义

## 构建与运行

```bash
pnpm install
pnpm build     # 产物在 dist/,Chrome/Edge 加载"已解压的扩展程序"指向该目录
pnpm dev       # 开发模式(自动重建)
```

模型配置:扩展设置 → 模型 → 添加供应商(OpenAI 兼容 baseURL + Key,或本地代理)。

## 安全说明

内部工具,仓库为私有。API Key 只保存在浏览器本地存储,不进仓库。


## 复杂任务运行时

任务运行记录使用浏览器原生 IndexedDB 保存，包含生命周期、追加事件、检查点和来源证据。高影响动作通过代码审批门阻塞，URL/Skill 工具策略不依赖模型提示词。恢复未知副作用时不会直接重放提交动作。

本地 PDF 仅通过用户已打开并授权访问文件网址的浏览器页面读取，并受文件大小限制；侧边栏关闭时本地文件读取请求会等待重新连接。


## 权限与数据留存

扩展只在用户当前任务需要的标签页上读取和操作页面。URL allow/deny 策略在浏览器动作执行边界检查；网页内容、PDF、截图和标题不会被当作权限来源。

任务运行状态、事件、检查点和来源证据保存在扩展本地 IndexedDB。删除聊天会话时会同步删除关联运行数据；运行历史按数量和事件/证据条目做本地保留清理。

## 本地 PDF

读取 `file://` PDF 前，需要先在 Chromium 扩展详情中开启“允许访问文件网址”，并让该 PDF 保持在浏览器标签页中打开。扩展不会提供任意本地路径浏览能力，文件桥接有请求 ID、超时和 10MB 大小限制。

文本型 PDF 使用 pdf.js 提取文本层；扫描件文本层为空时可使用视觉模型读取指定页面。MVP 不宣称内置 OCR。

## 模型与隐私

页面内容只发送到用户配置的模型供应商/兼容 API。任务事件不记录 API Key；运行时指标只保存模型/供应商信息、步骤、估算 Token 和耗时等审计数据。

## 任务恢复

关闭 Side Panel 不会取消后台任务。Service Worker 重启后运行会进入 interrupted，重新连接后可以从持久检查点恢复。对执行结果未知的浏览器写操作，恢复前会检查后置条件；无法确认时会阻止自动继续，不会盲目重复提交、删除或支付。

高影响动作需要一次性用户确认；页面跳转或动作参数变化会使原确认失效。
